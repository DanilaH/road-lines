- Повтор текущего hint для того же id/version/prefix использует оплаченный ответ в памяти. Новый prefix требует обычного solver-запроса; UNKNOWN не оплачивается. Кэш не переживает перезапуск.
- Три механических запрета получают локальный ободок, короткий текст и тихий ограниченный cue. Путь и кошелёк не меняются.
- Головка выделяется после отпускания; инструкция объясняет продолжение с конца, на механических полях показывает текущую цель.
- Недоступный offer подтверждается без модального прерывания Continue; x5 скрыт до рекламного этапа. Ledger/cadence сохранён. Подтверждение gift продолжает ровно один переход, Back остаётся на результате; ошибка ack требует восстановления авторитетного сохранения.

- Превью используют общий ромб старта; цифры Road Nunito загружаются перед renderer.
- Continue доступно с ~400 мс вместо 650; эффекты остаются. Сбор по добровольному нажатию короче. Награда сохраняется до presentation.
- Вместо нескольких полных redraw на один input update: dirty state, максимум один rebuild за Phaser update. Стабильные theme/DPR и стили цифр пропускаются; pointermove не перестраивает меню/HUD и не планирует resize. Статический слой отдельно не кешируется: сначала устранена доказанная избыточная работа.

## Регрессия / ограничения
Полный browser smoke обновлён под gift Continue и пропуск недоступного предложения; отдельный UX smoke включён в App CI. Полные результаты inspect/production и Android нужно проверять по workflow конкретного code commit; текущий документ не утверждает успех ещё выполняющегося прогона.
