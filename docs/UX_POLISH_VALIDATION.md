# UX / feel polish — 2026-10-31

Исходный аудит: `72e6404a2a7bb312a8325ded8dbfb46fb1d94c6b`. Банк, правила, цены и save v3 не менялись.

## Изменения
- Один повтор текущего hint для того же id/version/prefix использует оплаченный ответ в памяти. Новый prefix требует обычного solver-запроса; UNKNOWN не оплачивается. Кэш не переживает перезапуск.
- Три механических запрета получают локальный ободок, короткий текст и тихий ограниченный cue. Путь и кошелёк не меняются.
- Головка выделяется после отпускания; инструкция объясняет продолжение с конца, на механических полях показывает текущую цель.
- Недоступный offer подтверждается без модального прерывания Continue; x5 скрыт до рекламного этапа. Ledger/cadence сохранён. Подтверждение gift продолжает ровно один переход, Back остаётся на результате; ошибка ack требует восстановления авторитетного сохранения.
- После конца набора primary ведёт к явному выбору, последний результат доступен вторично.
- Превью используют общий ромб старта; цифры Road Nunito загружаются перед renderer.
- Continue доступно с ~400 мс вместо 650; эффекты остаются. Сбор по добровольному нажатию короче. Награда сохраняется до presentation.
- Вместо нескольких полных redraw на один input update: dirty state, максимум один rebuild за Phaser update. Стабильные theme/DPR и стили цифр пропускаются; pointermove не перестраивает меню/HUD и не планирует resize. Статический слой отдельно не кешируется: сначала устранена доказанная избыточная работа.

## Проверено локально
- `npm run check`: manifest/content validator/typecheck и 157 tests в 23 файлах.
- `node tools/ux-smoke.mjs --run`: production build; 9 групп сценариев; 320×568 / 360×800 / 390×844 / 412×915 / 576×1280, classic и neon, reduced motion для neon.
- Повтор hint: 3 → 2 → 2 при том же prefix; на изменённом prefix → 1. Отпускание/продолжение, reverse, каждый тип запрета и истечение объяснения.
- Ноль записей CSS-переменных темы при принятом и отклонённом route update. Это не замер FPS.
- Десятая победа продолжает без недоступного окна. Gift подтверждается и продолжает один раз; двойной click безопасен; Back не запускает скрытый переход; disk-full не теряет деньги, после reload можно продолжить.
- Конец набора остаётся в своём наборе; главная кнопка дома предлагает выбрать набор.
- Каталог содержит новые маркеры, позднее смешанное поле и инструкция помещаются над зарезервированным баннером. Page errors отсутствуют.

Исследовательские данные и WebM находятся в `.test-output/ux-polish/` (ignored). GIF — реальные записи production UI с подготовленными локальными save fixtures, без сгенерированных игровых кадров.

## Регрессия / ограничения
Полный browser smoke обновлён под gift Continue и пропуск недоступного предложения; отдельный UX smoke включён в App CI. Полные результаты inspect/production и Android нужно проверять по workflow конкретного code commit; текущий документ не утверждает успех ещё выполняющегося прогона.

Headless Chromium/CDP touch не подтверждает нативные ощущения. Физический Android: проверить быстрый палец и захват головки, время кадра на сложном поле, громкость rejection cue, вибрацию, Back/фон. Реальная реклама, RU/EN и signed release остаются отдельными этапами.
