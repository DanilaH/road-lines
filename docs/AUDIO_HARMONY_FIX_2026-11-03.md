# Звук после замечания о диссонансе

Дата:3 ноября2026. Пользователь сообщил, что pitch variation сделала звук неровным, неуместным и неприятным. Подтверждённые причины в коде: различная исходная частота каждого strike, хроматические фразы со случайным detune, перенос тональности на уровне и независимые C/D/B-flat reward chords; длительные клеточные хвосты накладывались при быстрых жестах. Прежняя проверка ограниченного playbackRate сама по себе не проверяла музыкальную согласованность.

Изменено:
- 12 cell strikes имеют единый C5=523.251Гц. Три близких тембра варьируют атаку/целочисленные гармоники, без случайной основной частоты или forced timbre change при каждом следующем уровне.
- Дискретные cell ноты C/D/E/G; соседний шаг не больше3 полутонов, диапазон квинты. Нет detune и key transposition. Семплы undo/button/reject и аккорды win/progress/gift/stars в общей тональности до мажор. Coins C/E/G/E без скольжения между нотами.
- RMS выровнен, громкость слегка снижена, хвосты короче. Старый route voice затухает20мс, cell/undo делят audio gate65мс; coins60мс. Нет очереди отложенных звуков. Haptics не менялись; один decoded buffer/context, прежние background/mute/dispose.

Автоматические проверки фиксируют tuning, ограничение наложений, отсутствие delayed replay и lifecycle. Они не подтверждают субъективную приятность динамика телефона. Не заявлено прослушивание физического устройства или сравнение с недоступным аудио конкурента.

Команды: npm run check; node tools/audio-smoke.mjs; node tools/celebrations-smoke.mjs; python3 tools/render-audio.py (numpy2.3.5, SHA воспроизводим). Детальные результаты и подписанный APK —AUDIO_HARMONY_FIX_EVIDENCE.json.
