## Сохранение и награды

Новый ценный тип результата требует GameSave v4 при прежнем storage key. v1–v3 мигрируют без сброса заработанного. Старый numeric sector7 остаётся300, а не превращается в тему. Старый клиент отвергает v4, чтобы не начислить монеты вместо зафиксированной темы при downgrade.

Theme ID принадлежит staged spin; commit атомарно сохраняет ownership и last spin. Auto-equip не навязывается. Reload/сбой подтверждения/двойное нажатие не дублируют grant. Если цель уже получена к commit — фиксируется fallback300, без reroll. Зафиксированный legacy result визуально сохраняет свой числовой сектор. Пока есть неполученные темы, средняя денежная часть колеса625/8=78.125 монеты плюс косметическая награда; после сбора всех925/8=115.625. Новые цены подсказок здесь не рассчитывались.

Подарок по-прежнему выдаётся в first-clear transaction на20/40/60/80. Presenter получает только баланс и milestone, не GameStore: монеты не зависят от animation callbacks. Ack failure сохраняет notice; после перезапуска подарок снова доступен без повторной выдачи. На фоне/resize/закрытии presenter завершает счётчик и удаляет таймеры/анимации/частицы.

Gift feedback разрешён под собственным UI blocker. Все причины блокировки звука учитываются отдельно: фон, пауза, конфликт, будущая реклама или startup failure останавливают его даже без нового aggregate activity edge. Возвращение из фона не повторяет старые cues. Vendor не изменён.
