# Этап 3 — меню и выбор задач

Дата: 2026-10-30. Это первая часть этапа 3; темы, покупки, предложение темы и колесо ещё не реализованы.

## Поведение
- Запуск открывает главное меню. Продолжение возвращает текущий prefix или сохранённый результат без новой выдачи монет.
- Наборы: первый содержит 15 реальных задач. Два следующих явно отмечены «Скоро», недоступны для входа и не содержат фиктивных уровней. Расширение до 3×30 остаётся этапом 5.
- Сетка в 5 столбцов: номера, замки, три звезды у пройденных, обводка текущего уровня. Следующий открывается после всех предыдущих; пройденные можно повторять.
- Выбор незавершённого уровня восстанавливает его маршрут. Выбор пройденного начинает повтор со старта; первая награда не повторяется.
- Пауза ведёт в наборы или главное меню. Escape/Android Back закрывает настройки/паузу, затем идёт сетка → наборы → меню. Из результата Back ведёт в меню; на главном меню остаётся в приложении.
- Последняя задача ведёт в сетку, без молчаливого зацикливания на первой. При всех 15 прохождениях показано завершение набора.
- Звук/вибрация доступны из главного меню и паузы. Клавиатурный фокус обходит только видимые кнопки; скрытое поле inert.
- Canvas сохраняется один; рендер спит вне игрового экрана. При уходе с результата отменяются FX/отложенные переходы; показанный баланс приводится к сохранённому.
- Баннерный слот зарезервирован на игре, паузе и сетке; на меню/наборах/результате скрыт. Это геометрия, рекламного SDK пока нет.

## Сохранения
Аддитивное поле drafts в JSON v1: версия уровня и законный prefix по id. Старые сохранения без drafts мигрируют с текущим маршрутом; кошелёк и отметки сохраняются. Текущий prefix остаётся авторитетным для своего draft. Неверные/устаревшие drafts не восстанавливаются; ценные progression-данные по-прежнему проверяются строго.
Перед выходом из игры flush prefix. Выбранная задача становится активной только после подтверждённой записи. Ошибка записи оставляет выбор/старый маршрут; неизвестный исход требует reload. Прежние Web Lock/baseline и атомарная first-clear награда сохранены.
