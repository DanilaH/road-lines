## Игровые границы
- Новые наборы доступны после первых трёх tutorial, независимо друг от друга.
- Внутри каждого — последовательное открытие, пройденные доступны для повторения.
- HUD/домашнее продолжение: 1–N / 2–N / 3–N. Сетка и счётчик принадлежат выбранному набору; домашний счётчик — всему банку.
- Завершение задачи 30 каждого набора ведёт в его итоговую сетку, с явной кнопкой выбора другого набора. Нет автоматического чужого старта.
- После всех 90 — сообщение «Все 90 задач пройдены!» и свободные повторы.
- Черновики, coins, темы и rewards используют прежний save v3. Первые 30 IDs/versions/данные не изменены.
- Глобальные подарки на 20/40/60/80: после 90 первых побед ровно 2200 монет без покупок/колеса. Повторы не продвигают gifts и не платят повторно.
- Для двух/трёх правил поле имеет дополнительные 48 CSS px снизу под подпись. Размеры renderer и hit-test используют один DOM host; результат использует прежнюю miniature layout.
