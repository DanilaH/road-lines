## Звук

`tools/render-audio.py` воспроизводимо создаёт `src/assets/audio/feedback.wav` и типизированные offsets в sound-bank.ts. Только offline NumPy; runtime/npm зависимости не добавлены. Mono 32 kHz /16 bit, 5.325 секунды, 340844 bytes. Загрузка не блокирует игру, AudioContext открывается на жесте; фон останавливает голоса и приостанавливает context. Отложенные звуки не проигрываются после возвращения. GIF без звука; субъективная оценка нового тембра остаётся за пользователем.

## Android-тесты без удаления старого приложения

У предыдущего и нового обычного CI APK разные сертификаты debug-подписи: такой APK не может обновить установленный предыдущий. Поэтому CI теперь явно собирает `.playtest` application ID с названием `Road Lines · тест`, рядом с обычным `com.danilah.roadlines`. Прогресс старого приложения остаётся в нём; отдельная тестовая установка начинает с собственного сохранения. Обычный `node tools/android.mjs` без ROAD_LINES_PLAYTEST=true сохраняет прежние ID/название. CI создаёт и явно использует `.test-output/android-signing/debug.keystore`, затем кэширует этот файл для следующих тестовых обновлений; потеря/истечение cache потребует отдельного решения подписи. Это не релизный ключ и не release acceptance.

## Проверки

Результаты и точные хэши — `PLAYTEST_FIXES_EVIDENCE.json`. Автоматизация использует production bundle, реальные pointer/touch события и сохранения, а не нарисованные макеты. Золотое кольцо в GIF — только указатель пальца из тестового стенда.

Физический палец, звучание/вибрация Android, FPS/нагрев и окончательная приёмка пользователем отдельно. Browser resource counters/heap и software-rendered frame measurements не доказывают отсутствие всех утечек или плавность на телефоне. В счётчиках ended-event закрытый AudioContext может не доставить последний event; внутренние voices очищаются и context закрыт.

Промежуточные проверки обнаружили две проблемы, которые не скрыты retry: старый all90-тест запрещал продолжение за полем (переписан под утверждённую механику), затем серия быстрых касаний обнаружила отсутствие compatibility click после captured свайпа (добавлена явная активация нижних кнопок по законченному pointer touch и проверка ровно одного action). Первые CSS-изменения прижатия не устранили второй случай; окончательный сценарий повторён 12 раз и включён в production smoke вместе с drag/cancel/mouse/keyboard.
