# Маркеры маршрута

31 октября 2026. Пользователь счёл прежние иконки недостаточно качественными, особенно начало и конец маршрута.

- Обычный старт: объёмный светлый жетон со срезанными вершинами, собственной тенью и двумя гранями. Не похож на кнопку сброса или круглую голову.
- Финиш: золотистое ромбовидное гнездо с углублённым центром. Последний ход вставляет светлый жетон. Клетчатый флажок и квадратная обводка удалены.
- Старт с номером 1 сохраняет номерной знак. На финише с номером цифра остаётся сверху, золотой ободок виден вокруг.
- Рисунок старта/финиша сохраняется на миниатюре результата. Сетка уровней и эмблема меню используют ту же геометрию, не отдельные символы.
- `src/presentation/markers.ts` — процедурные грани и SVG path. Нет новых картинок, текстурных объектов, анимационных циклов, зависимостей или изменений правил.

Проверка: `npm run check` — 156 tests / 23 files, TS, manifest, независимый аудит банка. Production build и целевые bank/mechanics browser flows проходят на пяти viewport и двух тёмных темах: сохранение/откат/worker hints, входы на финиш и номера, компоновка смешанных правил. Проверяется также наложение номера и финиша. Полный банк и экономика не менялись; повторный человеческий плейтест всех 90 ради декоративных маркеров не заявлен. Физическая Android-приёмка не выполнена.
Демонстрация снимается из production renderer с подготовленным local save для выбора уровня, реальными pointer moves и обычной победой. Это не запись телефона.
